HISTORY AND ORIGIN OF C

1. C is a general-purpose, procedural programming language.
2. C was developed by Dennis Ritchie.
3. It was developed at Bell Laboratories.
4. C was developed around 1972.
5. C evolved from the B programming language.
6. B was developed by Ken Thompson.
7. B was influenced by BCPL, developed by Martin Richards.
8. Much of UNIX was rewritten in C in 1973.
9. C was designed for efficient system programming.
